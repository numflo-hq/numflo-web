# Spanish style guide (es)

Rules every Spanish string must follow (SDLC §4.4, step 2).

1. **Variant:** neutral international Spanish. Avoid words used in only one country (see the glossary).
2. **Address the reader as "tú"**, in a friendly, clear tone: "Calcula tu cuota", not "Calcule su cuota".
3. **Numbers in running text** follow RAE guidance: space for thousands, comma for decimals, and no
   separator for four-digit numbers: `250 000`, `2013,98`, `7,5 %` (space before %).
   Numbers shown by the calculator are formatted automatically by currency.
4. **Punctuation:** opening `¿` and `¡` are required; use «comillas latinas» for quotes.
5. **Capitalisation:** sentence case in headings ("Calendario de pagos", not "Calendario De Pagos").
6. **Length:** page titles ≤ 60 characters, meta descriptions ≤ 155 (checked automatically).
7. **Meaning over words:** translate what the English means, never word by word. The independent
   back-translation review (step 3) must produce English with the same meaning as the source.
